# D21 · WF-L2-3 模板验证结果页（Template Validation Report Page）

**文档编号：** D21  
**文档名称：** WF-L2-3 模板验证结果页线框图  
**来源状态：** Newly Added  
**说明：** 需求规格说明书 v5.3 §6.1 及 WF-L2-2（D20）中提及"点击[验证模板]跳转 WF-L2-3"，UCG-01 US-14 中描述了验证结果的展示要求，但整体文档包中未包含 WF-L2-3 的具体线框图。本文档依据 D01 §FR-08、D18 `GET /api/templates/:id/validation-reports/latest` 响应结构及 D03 `ValidationReport`/`ValidationIssue` 数据模型补充生成。  
**新增理由：** 外包前端团队需要具体的页面区域划分、交互元素规格和状态处理逻辑，仅有功能描述无法实现页面。  
**格式规范：** 与 WF-L2-1（D19）、WF-L2-2（D20）格式保持一致。  
**版本：** v1.0  
**生成日期：** 2026-04-22  

---

## 📘 页面概述

模板验证结果页展示最近一次对当前模板执行验证所生成的 `ValidationReport`，包括通过/失败总体状态、全部 `ValidationIssue` 明细（按 severity 分组展示），并提供错误定位跳转、一键修复和日志导出功能。

**页面入口：**
- 从 WF-L2-2 模板编辑器顶部工具栏点击 [验证模板] 按钮
- 从 WF-L2-1 模板列表页卡片操作点击 [验证模板]

**页面出口：**
- 点击 [返回编辑器] → WF-L2-2 模板编辑器（若从编辑器进入则保留编辑状态）
- 点击 [前往模板] → WF-L2-2 模板编辑器（若从列表页进入）
- 点击错误条目中的 [定位] → 跳转到 WF-L2-2 并高亮对应节点/边

## 区域说明

### A区 — 顶部导航栏

| 元素 | 类型 | 说明 |
|------|------|------|
| [← 返回编辑器] | 按钮（次要） | 返回 WF-L2-2，若从列表进入则显示"前往模板" |
| 模板名称 | 文本 | 当前验证的模板名称，只读 |
| [重新验证] | 按钮（主要） | 重新调用 `POST /api/templates/:id/validate`，刷新结果 |
| [导出日志] | 按钮（次要） | 下载验证报告 JSON 文件 |

### C区 — 问题分类过滤栏

| 过滤选项 | 徽章颜色 | 说明 |
|---------|---------|------|
| 全部 N | 灰色 | 显示所有问题 |
| ● 错误 N | 红色 | 仅显示 `severity=Error` 的条目 |

#### 问题条目字段规格

每条问题条目展示如下字段：

| 字段 | 数据来源 | 说明 |
|------|---------|------|
| severity 徽章 | `ValidationIssue.severity` | `Error` 红色 ● / `Warning` 橙色 ▲ / `Info` 蓝色 ℹ |
| 类型标签 | `ValidationIssue.type` | 显示类型代码的中文名称（见下方映射表） |
| 工作流 | `ValidationIssue.workflowId` | 若有则显示，格式：`{name} ({id})` |
| 节点 | `ValidationIssue.nodeId` | 若有则显示，格式：`{label} ({id})` |
| 问题描述 | `ValidationIssue.message` | 直接渲染文本，phaseCode 以 `displayName(code)` 格式展示 |
| 操作按钮 | — | 根据 type 动态显示（见下方操作按钮规则） |

**ValidationIssue.type 中文名称映射：**

| type 值 | 中文显示名称 |
|---------|------------|
| `no_workflow` | 无工作流 |
| `empty_workflow` | 空工作流 |
| `phase_out_of_range` | 阶段不合法 |
| `phase_disabled` | 阶段已禁用 |
| `non_standard_phase` | 阶段非标准 |
| `cycle_detected` | 循环依赖 |
| `depth_exceeded` | 深度超限 |
| `isolated_node` | 孤立节点 |

**操作按钮规则（按 type 动态显示）：**

| type | 按钮 | 行为 |
|------|------|------|
| `phase_out_of_range`、`phase_disabled` | [🔍 定位到节点]、[✏️ 修改节点阶段] | 定位：跳转编辑器并高亮节点；修改：打开节点属性面板并聚焦阶段字段 |
| `cycle_detected` | [🔍 高亮循环路径]、[🗑 删除某条边] | 高亮：跳转编辑器并以红色标注循环路径；删除：展示循环路径边列表供选择删除 |
| `isolated_node` | [🔍 定位到节点] | 跳转编辑器并高亮孤立节点（黄色边框） |
| `empty_workflow` | [🔍 定位到工作流] | 跳转编辑器并定位到该工作流泳道 |
| `no_workflow` | — | 无定位操作（全局问题） |
| `depth_exceeded` | — | 无操作按钮，仅展示警告文字 |

## 页面状态处理

### 状态1：正常展示（有 ValidationReport）

展示 B区总览 + C区过滤栏 + D区问题列表 + E区操作区，参见上方线框图。

### 状态2：无报告（REPORT_NOT_FOUND）

隐藏 C区、D区、E区，B区显示"暂无验证报告"提示（见 B区"无报告状态"展示）。

### 状态3：加载中

B区显示骨架屏，D区显示 3 个占位条目的骨架屏。

### 状态4：重新验证中（点击[重新验证]后）

顶部显示蓝色进度条，[重新验证] 按钮变为 loading 状态并禁用，完成后刷新所有区域内容。

### 状态5：全部通过（valid=true，无任何 issue）

B区显示通过状态（含[立即发布模板]按钮），C区统计数字全为 0，D区显示"✅ 本次验证无任何问题"空状态提示，E区正常展示。

## 定位交互说明

用户在 WF-L2-3 点击 [🔍 定位到节点] / [🔍 高亮循环路径] 后：

1. 页面跳转到 WF-L2-2 模板编辑器（若当前在独立标签页，则在编辑器标签页内定位）
2. 画布自动滚动到目标节点/边所在位置，并居中显示
3. 目标节点以高亮动画闪烁 2 秒（错误=红色边框，警告=橙色边框）
4. 页面 URL 更新 hash，支持刷新后还原定位状态（如 `#node-requirements.vision`）
