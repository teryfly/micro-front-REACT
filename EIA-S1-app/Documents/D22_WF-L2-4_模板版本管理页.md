## 📘 页面概述

模板版本管理页展示当前模板的历史版本列表，支持任意两个版本之间的差异对比（左右分屏），以及版本回滚和版本复制操作。

> **重要设计说明：** S1 的"模板版本"指的是 **RUPTemplate 结构快照**（工作流拓扑、节点、依赖边的整体快照），与 S3 文档版本（DocumentVersion）完全独立。MVP 阶段版本快照通过保存时自动留存 `updatedAt` 时间戳标记，不单独建立 VersionSnapshot 表，以 `rup_template.updatedAt` + `validation_report.createdAt` 作为版本时间锚点。

**页面入口：**
- 从 WF-L2-1 模板列表页卡片操作点击 [查看版本]
- 从 WF-L2-2 模板编辑器顶部工具栏点击 [版本历史]

**页面出口：**
- 点击 [返回列表] → WF-L2-1
- 点击 [打开编辑器] → WF-L2-2
- 点击 [回滚到此版本] → 执行回滚后自动跳转 WF-L2-2

### B区 — 版本列表区

#### B1 — 版本选择器（对比操作）

```
┌──────────────────────────────────────────────────────────────────┐
│  选择要对比的两个版本：                                           │
│                                                                  │
│  版本 A（旧）：[v1 (初始版本) ▼]                                │
│  版本 B（新）：[v3 (当前版本) ▼]                                │
│                                                                  │
│  [执行对比]                                                      │
└──────────────────────────────────────────────────────────────────┘
```

- 两个下拉框均从版本历史时间线（B2）加载选项

- 不允许两个下拉框选择相同版本（选同一版本时 [执行对比] 禁用，提示"请选择不同的版本"）

**版本条目字段规格：**

| 字段 | 数据来源 | 说明 |
|------|---------|------|
| 版本号 | 系统生成（按 updatedAt 排序，v1 最旧） | 如 v1、v2、v3；当前版本标注"当前版本" |
| 状态 | `rup_template.status`（该时刻快照） | 已发布 ✅ / 草稿 📝 / 已归档 🗄 / 验证失败 ❌ |
| 保存时间 | `rup_template.updatedAt` | UTC 转本地时区显示 |
| 工作流数 | 快照数据 | 该版本时的工作流数量 |
| 节点数 | 快照数据 | 该版本时的节点总数 |
| 边数 | 快照数据 | 该版本时的依赖边总数（流程内 + 跨流程） |

**版本条目操作按钮规则：**

| 操作 | 显示条件 | 行为 |
|------|---------|------|
| [设为版本A] | 始终显示 | 将该版本设为对比左侧（旧版本） |
| [设为版本B] | 始终显示 | 将该版本设为对比右侧（新版本） |
| [回滚到此版本] | 非当前版本 | 弹出确认对话框后执行回滚（见下方回滚流程） |
| [复制为新模板] | 始终显示 | 以该版本结构克隆创建新模板（category=Custom，status=Draft） |

> **MVP 版本管理说明：** MVP 阶段版本管理基于保存时间点标记，不支持自定义版本备注（`備注` 字段列在设计中预留但 MVP 不展示）。版本数量上限：默认保留最近 20 个版本，超出后最旧版本不可回滚（灰化回滚按钮，Tooltip 说明"历史版本保留上限已达，此版本不支持回滚"）。

| 变更类型 | 左侧（旧版本）展示 | 右侧（新版本）展示 | 标注 |

## 回滚流程

用户点击 [回滚到此版本] 后触发以下交互流程：

```
Step 1：显示回滚确认对话框
──────────────────────────────────────────────────────
"回滚确认

 即将将模板「标准RUP模板」回滚到：
 版本 v2（2026-03-15 10:30）

 回滚后：
 ● 当前版本（v3）的所有修改将被覆盖
 ● 模板状态将变为 Draft（需重新保存发布）
 ● 此操作不可通过页面Undo恢复（但 v3 仍保留在版本历史中）

 [确认回滚]  [取消]"
──────────────────────────────────────────────────────

Step 2：执行回滚
- 调用回滚 API（待 D18 补充：PUT /api/templates/:id/rollback）
- 显示进度指示器

Step 3：回滚成功
- 显示成功提示：
  "已成功回滚到 v2，当前版本为 Draft 状态。
   建议检查模板内容后重新发布。"
- 版本历史更新：在时间线顶部新增一条"v4（从v2回滚）"条目
- 自动跳转到 WF-L2-2 编辑器

Step 4：回滚失败
- 显示错误提示（含错误原因）
- [重试]  [取消]
```

## 无版本历史状态

当模板仅有一个版本时（刚创建未保存过第二次），B2 时间线仅显示"v1 初始版本"，B1 版本对比选择器禁用（灰化），C区显示以下空状态：

```
┌───────────────────────────────────────────────────────────────────────┐
│                                                                       │
│              📋 暂无可对比的版本历史                                  │
│                                                                       │
│     该模板目前仅有一个版本，无法进行版本对比。                        │
│     每次保存模板后，系统会自动记录新版本。                            │
│                                                                       │
│                    [前往编辑器]                                       │
│                                                                       │
└───────────────────────────────────────────────────────────────────────┘
```
